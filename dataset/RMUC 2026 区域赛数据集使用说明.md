# RMUC 2026 区域赛数据集 — 字段说明

本数据集为 2026 RoboMaster 超级对抗赛（RMUC）东部 / 南部 / 北部三大区域赛的比赛过程数据。
文件格式为单个 SQLite 文件，内含三张表：`matches`、`timeseries`、`events`。

## 基本概念
- **一场(match)含多局(round)**：一场对阵通常打 3~5 局分胜负。表中用「场次号」标识一场，「局号」标识该场内的第几局。
- 场次显示为 `【东部赛区】第67场`。三表都带「赛区 / 场次号 / 赛程 / 局号 / game_id」，可据此互相关联。
- 时刻均为「距开局秒数」（0 起），三表时间对齐，可按秒拼接。
- 阵营分「红 / 蓝」；每台机器人所属队的学校名直接写在行内，便于筛选。

## 表 1：matches — 场次/局次索引（每行一局）
| 字段 | 含义 |
|---|---|
| 赛区 | 东部赛区 / 南部赛区 / 北部赛区 |
| 场次号 | 该赛区内的场次编号 |
| 赛程 | `【赛区】第N场` |
| 局号 | 该场内第几局（1~5） |
| game_id | 局唯一编号（关联另两张表） |
| web_game_id | 官网局编号 |
| 红方学校 / 蓝方学校 | 对阵双方学校名 |
| 胜方 | 红 / 蓝 |
| 开始时间 / 时长秒 | 该局开始时刻 / 时长（秒） |

## 表 2：timeseries — 逐秒状态（每行 = 某局某秒某机器人）
覆盖每队 8 类实体：英雄 / 工程 / 步兵3 / 步兵4 / 空中 / 哨兵 / 基地 / 前哨站。
（基地、前哨站为建筑，其血量也在本表；空中=无人机，仅在其出动时段有数据行。）

| 字段 | 含义 / 用法 |
|---|---|
| 赛区 / 场次号 / 赛程 / 局号 / game_id | 场次维度 |
| 时刻秒 | 距开局秒数 |
| robot_id | 机器人编号 |
| 机器人类型 | 英雄 / 工程 / 步兵3 / 步兵4 / 空中 / 哨兵 / 基地 / 前哨站 |
| 阵营 | 红 / 蓝 |
| 学校名 | 该机器人所属队的学校 |
| 对手学校 | 对方学校 |
| 当前血量 / 最大血量 | 该秒血量 |
| x / y / z | 场地坐标 |
| 枪口朝向 | 枪口罗盘朝向 |
| 底盘功率 | 当前底盘功率 |
| 小热量 / 小热量上限 | 17mm 枪口热量及上限 |
| 大热量 / 大热量上限 | 42mm 枪口热量及上限 |
| 累计17mm发弹 | 截至该秒累计发射的 17mm 弹量（**累计值，非剩余**）。步兵/空中/哨兵有值；首发前为 0；不发 17mm 的机器人为空 |
| 累计42mm发弹 | 截至该秒累计发射的 42mm 弹量。仅英雄有值；其余为空 |
| 队伍总金币 | 该队截至该秒累计获得的金币 |
| 队伍剩余金币 | 该队当前剩余金币 |
| 是否易伤 | 0/1。该秒该机器人**被对方雷达标记高亮**。只在被敌方雷达标记时为 1 |

## 表 3：events — 触发事件（每行 = 一次事件，由「事件类型」区分）
通用字段：赛区 / 场次号 / 赛程 / 局号 / game_id / 时刻秒 / robot_id / 机器人类型 / 阵营 / 学校名（事件主体），
以及 目标robot_id / 目标类型（受击、飞镖等有目标的事件用）、类别、数值、备注。

| 事件类型 | 含义 | 类别 | 数值 | 备注 |
|---|---|---|---|---|
| 发弹 | 一次射击 | 17mm / 42mm | — | — |
| 受击 | 一次受到伤害（已剔除持续伤害等无意义扣血） | 17mm / 42mm / 撞击 / 飞镖 / 判罚 | 扣血值 | robot_id 为受击方 |
| 装配成功 | 科技核心装配成功 | 等级N | 耗时（秒） | 受罚（如有） |
| 能量机关 | 能量机关击打 | rune_type | 环数 | 激活臂数 / 平均环数 |
| 飞镖闸门开 | 飞镖发射闸门开启 | — | 开启次数 | — |
| 飞镖命中 | 飞镖命中 | 飞镖命中 | 伤害值 | 目标类型 = 基地 / 前哨站 |
| 雷达反制UAV | 无人机被对方雷达锁定反制 | 被反制 | — | 阵营为被反制方，反制方为对手 |
| 增益 | 获得一次增益 | 飞坡 / 过中央高地 / 台阶跨越 / 小能量机关增益 / 大能量机关增益 | — | — |

## 使用提示
- 三表用 `game_id` 关联到具体一局；用「赛区 / 学校名 / 机器人类型 / robot_id / 赛程」做切片筛选。
- 「累计发弹」是累计值，某段时间发弹数 = 末秒累计 − 首秒累计。
- 分析伤害用 events 的「受击」；分析射击节奏用「发弹」或 timeseries 的累计发弹。
- 空中（无人机）只有出动时段的数据行，统计时注意其行数天然少于地面机器人。
